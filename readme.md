# Campus Event Finder

A responsive web-based platform for York University students to easiley discover campus events.

## Project Overview

Campus Event Finder centralizes event discovery for York University students, providing an intuitive interface to browse, search, filter, and save campus events. The platform addresses the problem of scattered event information across multiple university pages by offering a streamlined, student-centered experience.

## Features

- Browse all upcoming campus events
- Filter events by category (Academic, Social, Sports)
- Filter events by date (upcoming, ongoing, future)
- Search events by keyword
- Save/bookmark events to personal list
- Create and edit personal events

## Setup Instructions

1. Clone this repository
2. Open `index.html` in your web browser
3. No build process or dependencies required

## Design Approach

The interface follows the high-fidelity prototypes developed during the design phase, with a focus on:
- Clean, minimalist aesthetic
- Clear visual hierarchy
- Consistent interaction patterns
- Accessibility (WCAG 2.1 compliant contrast)
- Mobile-first responsive design
